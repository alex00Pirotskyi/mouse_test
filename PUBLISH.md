# Publish Mudra Smart Cursor — mouse_test

The source code is in https://github.com/alex00Pirotskyi/mouse_test (main).

Expected GitHub Pages URL: https://alex00pirotskyi.github.io/mouse_test/

If GitHub Pages is not automatically enabled by the workflow, open
https://github.com/alex00Pirotskyi/mouse_test/settings/pages
and select **GitHub Actions** under **Build and deployment → Source**.

The self-contained bookmarklet is generated by the landing page.
It does not move the operating-system cursor; true re-centering requires
virtual Pointer Lock mode.

For local changes, run `npm run build` and `npm run check`.
