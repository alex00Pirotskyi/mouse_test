Precision layer

All the control features

Normal cursor assistance uses HID input. Firmware-linked virtual mode reads a local companion on macOS or Windows that accesses the existing Mudra FFF0 GATT service. No firmware modifications are required.

01 / MAGNET

Magnetic targeting

Detects nearby links and controls and highlights the best candidate with a generous target radius.

02 / STICKY

Sticky selection

Hysteresis retains a selected element through small hand tremors without rapidly switching targets.

03 / PRECISION

Adaptive fine movement

Slows virtual cursor motion around actionable targets. Normal OS cursor speed is unchanged.

04 / CLICKS

Optional click assist

Redirects genuine near-miss clicks to eligible controls. Disabled by default for safety.

05 / DWELL

Optional dwell click

Hold near a button to activate it. Requires a stable target and avoids some risky controls.

06 / CENTER

Shake-to-recenter

Re-center the virtual cursor with one action. Pointer Lock gives continuous relative motion at screen edges.

Browser-only feasibility

No-install BLE test first

Before installing anything, open the Web Bluetooth test on Chrome/Edge while your Mudra Band remains connected to the OS as a HID mouse. It checks previously authorized devices without scanning, then optionally offers a one-time filtered browser device chooser. It reads FFF0/FFF1, the Air Touch system map and battery if accessible. Flutter Web would have the same browser limitations.

Installation

Use your already-paired Mudra Band

Launch the downloaded desktop companion once. It opens its own local Smart Cursor page and begins reading device status automatically—no separate browser permission or Connect button. Windows uses paired devices; macOS uses system-connected FFF0 devices. No Bluetooth scans, re-pairing or firmware changes. Air Touch OFF restores native HID; ON allows virtual mode after a user click.

Compatibility

Things browsers won't let us override

A bookmarklet cannot reposition or slow the operating-system cursor. The companion's local page uses same-origin API access without cross-origin loopback prompts; on other websites the bookmarklet may still require loopback permission (Chrome extension recommended). If the browser shows Companion offline, open http://127.0.0.1:8765/api/status on that computer: no response means the native companion is not running/listening. On macOS, the no-scan helper can only see system-connected peripherals exposing FFF0; it cannot list all paired devices. Virtual mode uses Pointer Lock and synthetic clicks, so some sites, embedded frames, protected controls, and drag-and-drop interactions may not work. Sticky selection is a visual targeting aid; it doesn't force native CSS :hover to stay active. Navigation/reloads end the bookmarklet session. Firmware-level orientation re-zeroing requires separate work on the Mudra Band itself.
