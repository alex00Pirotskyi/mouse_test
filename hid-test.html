Firmware HID keyboard test

No installation, no Bluetooth GATT and no re-pairing. Keep Mudra connected as a normal HID mouse. We only observe trusted keyboard events from the currently focused tab.

1 · Arm the test

This page reacts to firmware reports only after you enable testing. Start with Right Ctrl / Right Alt. Physical keyboard keys generate the same events.

2 · Send firmware HID key pulse

Send Right Ctrl key-down and key-up (modifier 0x10), then Right Alt key-down and key-up (0x40). Pressing physical right Ctrl/Alt is also a useful browser-only preview. Pointer Lock might be denied until the page receives a valid activation gesture.
