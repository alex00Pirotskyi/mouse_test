Precision layer

All the control features

Normal cursor assistance uses HID input; firmware-linked virtual mode reads a Windows companion that opens the OS-paired Mudra FFF0 GATT service. No firmware modifications are required.

01 / MAGNET

Magnetic targeting

Detects nearby links and controls and highlights the best candidate with a generous target radius.

02 / STICKY

Sticky selection

Hysteresis retains a selected element through small hand tremors without rapidly switching targets.

03 / PRECISION

Adaptive fine movement

Slows virtual cursor motion around actionable targets. Normal OS cursor speed is unchanged.

04 / CLICKS

Optional click assist

Redirects genuine near-miss clicks to eligible controls. Disabled by default for safety.

05 / DWELL

Optional dwell click

Hold near a button to activate it. Requires a stable target and avoids some risky controls.

06 / CENTER

Shake-to-recenter

Re-center the virtual cursor with one action. Pointer Lock gives continuous relative motion at screen edges.

Compatibility

Things browsers won't let us override

A bookmarklet cannot reposition or slow the operating-system cursor, and Chrome may require permission to access 127.0.0.1 (Loopback network). Virtual mode uses Pointer Lock and synthetic clicks, so some sites, embedded frames, protected controls, and drag-and-drop interactions may not work. Sticky selection is a visual targeting aid; it doesn't force native CSS :hover to stay active. Navigation/reloads end the bookmarklet session. Firmware-level orientation re-zeroing requires separate work on the Mudra Band itself.
