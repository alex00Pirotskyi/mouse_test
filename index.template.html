Precision layer

All the control features

Virtual mode can now be triggered directly by trusted keyboard HID reports. Right Ctrl (HID 0xE4) enables; Right Alt (0xE6) disables. The optional BLE companions are no longer required for cursor switching.

01 / MAGNET

Magnetic targeting

Detects nearby links and controls and highlights the best candidate with a generous target radius.

02 / STICKY

Sticky selection

Hysteresis retains a selected element through small hand tremors without rapidly switching targets.

03 / PRECISION

Adaptive fine movement

Slows virtual cursor motion around actionable targets. Normal OS cursor speed is unchanged.

04 / CLICKS

Optional click assist

Redirects genuine near-miss clicks to eligible controls. Disabled by default for safety.

05 / DWELL

Optional dwell click

Hold near a button to activate it. Requires a stable target and avoids some risky controls.

06 / CENTER

Shake-to-recenter

Re-center the virtual cursor with one action. Pointer Lock gives continuous relative motion at screen edges.

No-install firmware HID

Keyboard events, no second BLE connection

Keep the Mudra Band connected as an OS HID mouse. When firmware Air Touch turns ON, send a short Right Ctrl key-down + key-up. When OFF, send Right Alt key-down + key-up. The webpage reacts to these events while focused. Test the keyboard and browser Pointer Lock behavior here. Any physical keyboard sending the same key is indistinguishable from Mudra; use the safe default Right Ctrl/Alt or F23/F24.

Compatibility

Things browsers won't let us override

The HID-only path cannot report battery percentage without a separate data channel and cannot tell firmware keys from physical keyboard keys. A bookmarklet cannot reposition or slow the operating-system cursor. The companion's local page uses same-origin API access without cross-origin loopback prompts; on other websites the bookmarklet may still require loopback permission (Chrome extension recommended). If the browser shows Companion offline, open http://127.0.0.1:8765/api/status on that computer: no response means the native companion is not running/listening. On macOS, the no-scan helper can only see system-connected peripherals exposing FFF0; it cannot list all paired devices. Virtual mode uses Pointer Lock and synthetic clicks, so some sites, embedded frames, protected controls, and drag-and-drop interactions may not work. Sticky selection is a visual targeting aid; it doesn't force native CSS :hover to stay active. Navigation/reloads end the bookmarklet session. Firmware-level orientation re-zeroing requires separate work on the Mudra Band itself.
